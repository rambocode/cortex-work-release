# Cortex Desktop

> 会听、会说、会动手的本地 AI 工作站。

[中文官网](https://rambocode.github.io/cortex-work-release/zh/) · [English website](https://rambocode.github.io/cortex-work-release/en/) · [下载最新版](https://github.com/rambocode/cortex-work-release/releases/latest) · [反馈与建议](https://github.com/rambocode/cortex-work-release/issues)

Cortex Desktop 是一款面向 macOS 的本地优先 AI 工作站。它不是只会聊天的窗口：你可以用文字或语音交代任务，让它研究资料、制作演示文稿、写作、操作电脑、运行自动化，并把可直接使用的结果交回来。

## 能做什么

- **语音对话**：本地唤醒与语音识别，支持持续对话、随时打断；音频不落盘、不上传。
- **真正动手**：在每次确认后操作鼠标、键盘、浏览器、终端与文件，解决没有 API 的工作。
- **一队子代理并行工作**：把研究、代码审查、事实核查等工作拆分给合适的 Agent，并看到全过程。
- **直接交付成品**：制作可编辑的 PPTX、研究报告、写作稿、网页、图表和其他文件，而不只是返回一段文字。
- **自动化与 Loop 工作流**：用自然语言创建定时任务，或搭建带条件、循环、人工审批和通知的工作流。
- **模型自己选**：连接已有的 Claude、ChatGPT、Copilot 等订阅或 API Key，内置目录覆盖 37 家供应商、1000+ 模型。

## 为什么是本地优先

会话、闪记、任务、自动化和记忆保存在你的 Mac；凭据放在系统钥匙串。执行写文件、点击、输入等真实操作前，Cortex 会逐次请求你的确认。

## 开始使用

1. 在 [Releases](https://github.com/rambocode/cortex-work-release/releases/latest) 下载适合 Apple Silicon 或 Intel Mac 的安装包。
2. 安装后，在设置中登录已有模型订阅或填入 API Key。
3. 直接交代一件具体的事，例如：「调研竞品更新，整理成一页 PPT，重要变化推给我」。

> 目前仅支持 macOS。需要自行接入一个模型供应商；已有订阅可以直接登录，也可以使用 API Key。
